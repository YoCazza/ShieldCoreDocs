For the full legal text, see the [Privacy Policy](https://shieldcore.app/privacy) and [Terms of Service](https://shieldcore.app/tos). This page summarizes how server data is handled.

## If ShieldCore is removed from your server

Removing or kicking the bot does **not** wipe anything straight away. Your settings, tickets, statistics, giveaways and so on stay for **31 days**. If you add ShieldCore back within that time, you continue where you left off. After 31 days without the bot, the data is cleaned up. Premium backups are kept for 90 days.

Servers that run a [custom bot](/custom-bot/overview) with the bot still in the server are never cleaned up.

<Note>
  Data that has been cleaned up cannot be brought back.
</Note>

## Blacklisted servers

If a server is blacklisted for breaking the rules, its data is removed immediately.

## Custom bot tokens

Tokens are stored **encrypted** and are never shown again after you save them.

## Cookies

The website asks for your consent for cookies. See the [Privacy Policy](https://shieldcore.app/privacy).
