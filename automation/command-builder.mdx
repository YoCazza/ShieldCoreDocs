---

The Command Builder lets you make custom slash commands for your server, for example `/rules`, `/apply` or `/socials`, and decide what they reply with.

Open **Command Builder** in the sidebar (under **Builders**).

## Create a command

<Steps>
  <Step title="Start a new command">
    Use the new command wizard, or begin from the **template gallery** for common commands.
  </Step>
  <Step title="Design the reply">
    Build the response as a message or an embed. Insert variables for dynamic values. A live preview shows how it looks in Discord, and you can run a simulation before it goes live.
  </Step>
  <Step title="Publish">
    The publish wizard registers the command in your server and shows progress. It is then available to members under `/`.
  </Step>
</Steps>

An interactive tutorial is available inside the builder, and you can import or transfer commands between servers.

## Limits

Free servers can have 2 active custom commands; Premium servers 25. Commands above the limit when Premium ends are kept but switched off. See [Free vs Premium](/plans).

<Tip>
  For anything that should happen automatically rather than on request, use a [workflow](/automation/workflows) instead.
</Tip>
