---
title: "Backups"
description: "Save your server structure and restore it when you need to."
---

Backups store your server's structure (channels, categories and roles with their settings) so you can restore it after a mistake, a raid or a nuke. Open **Backups** in the sidebar.

## Backup control center

Create, preview, import and apply templates in one place. Select a backup on the left to open a Discord-style preview of the channels and roles it contains.

<Steps>
  <Step title="Create a backup">
    Press **Create backup**. Free servers have a cooldown between manual backups; Premium has a much shorter one. See [Free vs Premium](/plans).
  </Step>
  <Step title="Preview it">
    Select the backup to browse channels, roles and permissions before doing anything.
  </Step>
  <Step title="Apply it">
    Press apply and confirm. ShieldCore shows warnings first.
  </Step>
</Steps>

<Warning>
  Applying a backup **removes the existing channels and roles first**, then restores the template. This cannot be undone. Create a fresh backup of the current state if you might want to return to it.
</Warning>

## Share codes and templates

You can paste a **share code** to preview a template, and import it to use as a starting point for another server.

## Premium extras

Premium servers can store more backups, create backups every 30 seconds apart, and enable **automatic backups** every 4, 8, 12 or 24 hours, with the latest automatic backups kept as history.
