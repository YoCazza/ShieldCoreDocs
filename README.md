# ShieldCore docs

Documentation for [ShieldCore](https://shieldcore.app), built with [Mintlify](https://mintlify.com).

- Pages are MDX files; navigation and branding live in `docs.json`.
- Logos are in `logo/` (`light.svg` for light mode, `dark.svg` for dark mode); the favicon is `favicon.svg`.
- Support server: https://discord.com/invite/FnaGHu2eEb

## Preview locally

```
npm i -g mint
mint dev
```

Open http://localhost:3000. Run `mint broken-links` to check links.
