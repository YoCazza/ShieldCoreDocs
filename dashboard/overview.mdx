The dashboard at [shieldcore.app](https://shieldcore.app) is where you configure ShieldCore. Log in with Discord, pick a server, and use the sidebar on the left.

## Sidebar sections

| Section | What you find there |
| --- | --- |
| **Dashboard** | Overview of your server and its activity. |
| **Setup** | The [setup wizard](/dashboard/setup-wizard). |
| **Settings** | [General](/settings/general), [bot identity](/settings/bot-identity), [custom bot](/custom-bot/overview), [subscription](/settings/subscription) and [audit log](/settings/audit-log). |
| **Server Logs** | A searchable, live log of moderation actions. See [Logging](/moderation/logging). |
| **Modules** | Switch modules on and configure them. See [Modules](/modules/overview). |
| **Commands** | The built-in slash commands. See [Commands](/moderation/commands). |
| **AutoMod**, **Anti-Nuke**, **Anti-Bot**, **Backups** | The [security](/security/automod) tools. |
| **Moderation Logs** | Choose which events are logged and where. |
| **Tickets** | Panels, configuration, history and transcripts. See [Tickets](/modules/tickets). |
| **Builders** | [Embed Builder](/automation/embed-builder), [Command Builder](/automation/command-builder) and [Workflows](/automation/workflows). |

## Handy features

<AccordionGroup>
  <Accordion title="Switch server">
    Use the server picker at the top of the sidebar. It lists every server where ShieldCore is installed and you have access, and remembers your recent ones.
  </Accordion>
  <Accordion title="Command palette and search">
    Press the search box (or use the command palette) to jump to any page or start an action such as **Create backup** or **Create workflow**. Use the arrow keys to move and Enter to open.
  </Accordion>
  <Accordion title="Favorites">
    Pin menu items to your favorites so the pages you use most are one click away.
  </Accordion>
  <Accordion title="Notifications">
    The bell icon opens your inbox with messages from ShieldCore, for example when a plan changes.
  </Accordion>
  <Accordion title="Language and theme">
    The dashboard is available in English, Dutch, German and French. Change the language and theme under **Settings → General**.
  </Accordion>
</AccordionGroup>

<Note>
  Until you finish the [setup wizard](/dashboard/setup-wizard), most of the sidebar stays locked.
</Note>
