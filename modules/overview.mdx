---

Modules are features you turn on per server. Open **Modules** in the sidebar to see them all. Each card has a switch, and a gear opens its settings. When a module is off, nothing runs but your settings are kept.

| Module | What it does |
| --- | --- |
| [Automatic Role](/modules/auto-role) | Give or remove roles when a member joins. |
| [Auto Responder](/modules/auto-responder) | Reply to trigger words with a reaction, message or embed. |
| [Welcome & Leave](/modules/welcome-leave) | Custom join and leave messages, with an optional welcome card. |
| [Reaction Roles](/modules/reaction-roles) | Let members pick roles with buttons, reactions or a dropdown. |
| [Giveaway](/modules/giveaway) | Run giveaways with a public live page. |
| Moderation Logs | Send moderation and event logs to channels. See [Logging](/moderation/logging). |
| [Creator Alerts](/modules/creator-alerts) | Announce new YouTube videos and Twitch streams. |
| [Sticky Messages](/modules/sticky-messages) | Keep a message near the bottom of a channel. |
| [Private Voice](/modules/private-voice) | Members create their own temporary voice channels. |
| [Suggestions](/modules/suggestions) | Collect ideas with votes and discussion threads. |
| [Tickets](/modules/tickets) | Private support tickets with transcripts. |

<Note>
  Some modules have plan limits (for example how many sticky messages). See [Free vs Premium](/plans).
</Note>

## Common tools in module settings

- **Live preview:** most message editors show how the message will look in Discord.
- **Template variables:** message fields offer a variable picker, such as the member's name or the server name.
- **Message type:** many modules let you choose a normal message or an embed.
- **Save bar:** unsaved changes are flagged at the bottom. Save when you are ready, or reset to undo.
