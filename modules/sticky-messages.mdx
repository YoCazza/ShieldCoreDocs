title: "Sticky Messages"
description: "Keep an important message near the bottom of a channel."
---

A sticky message is reposted so it stays visible as the chat moves on, ideal for rules or instructions.

## Create a sticky message

1. Open **Sticky Messages** and choose **Create Sticky Message**.
2. Pick the channel and write the message (normal message or embed).
3. Save.

ShieldCore reposts the message using **smart cooldowns**, so it does not spam active channels. When a sticky is disabled, no new reposts are scheduled.

## Limits

Free servers can have 2 sticky messages and Premium servers 25. Embed stickies carry a ShieldCore footer on Free, and a **custom footer** on Premium. See [Free vs Premium](/plans).
