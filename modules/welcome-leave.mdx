---
title: "Welcome & Leave"
description: "Greet new members and say goodbye with custom messages."
---

Send a message when someone joins and another when they leave. Each one can be turned on separately.

## Join and leave messages

For each event, choose:

- the **channel** the message is posted in,
- the **type**: normal message or embed,
- whether to **show the user's avatar**,
- the **message content** or the **embed content** (title, description and so on).

Use **template variables** to personalize the text, for example the member's name or the server name. The variable picker lists what is available, and the **live preview** shows the result.

If an event is disabled, enable it first to edit its message.

## Welcome card

The welcome card editor lets you design an image card that is sent with the join message, so every new member gets a personal welcome.

<Tip>
  Keep the welcome message short and point to your rules and role-picker channels.
</Tip>
